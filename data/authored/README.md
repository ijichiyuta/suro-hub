# 自作機種（新台の手動追加）

コピー元（期待値サイト／研究所）に無い新台を、既存機種と同じ形式で追加するための仕組み。

## 追加のしかた
1. `_template.json` を複製し、`<好きな名前>.json`（例 `monkey6.json`）にリネーム。`_` 始まりのファイルは無視される。
2. 中身を埋める:
   - `name`（必須・正式名称）／`maker`／`thumb`（画像URL・空OK）／`isNew`（新台なら true）／`pop`（人気度＝並び順。20前後で上位）
   - `nerai`（狙い目タブのHTML）… 見出し `<h3>`・段落 `<p>`・表 `<table>` が使える。**期待値表もここに `<table>` で貼る**。
   - `spec`（解析・設定判別タブのHTML）
   - `shukei`（大量集計タブのHTML・任意）
3. 反映: プロジェクト直下で
   ```
   node scripts/build-data.mjs && node scripts/build-calc.mjs && npm run build
   git add -A && git commit -m "新台追加: <機種名>" && git push
   ```
   → 機種一覧に出て、狙い目/解析/大量集計タブに表示される（他機種と同じ形式・フリーミアムのプレビュー/会員限定も自動適用）。

## メモ
- 文章は**自作＝オリジナル**なのでリライト不要。そのまま表示される。
- 同じ `name` で再作成すると同じ機種を上書き更新できる（内容差し替え）。
- 期待値の算出は「期待値計算ツール（別途）」で出した数値・期待値表を `nerai` に貼る想定。
- HTMLに貼る数値・表は自由（情報不変ゲートは自作機種には適用されない＝自分の責任で正しい値を入れる）。
