## 1. サービス概要

### 1.1 目的・背景
パチスロ／パチンコ（スマスロ・スマパチ）の**期待値稼働（ハイエナ立ち回り）に必要な情報**——狙い目ゲーム数・天井・ゾーン・やめどき・設定判別・大量集計——を、**1機種1ページ**に整理して提供する個人運営の有料サブスクリプションサービス。

ホール（店内）で開いて「打つ前に、勝てる台かひと目でわかる」ことを最優先に設計している。

### 1.2 提供価値
- **即断できる情報密度**：機種ごとに立ち回りに必要な数値が構造化され、タブ＋クイックナビで最短到達。
- **店内でも軽い**：一度見た機種は電波が弱くても即表示（PWA / オフライン対応）。
- **付随ツール**：期待値計算シミュレーター、稼働ロガー（収支記録）、お気に入り・メモの端末間同期。

### 1.3 ターゲットユーザー
- スマスロ／スマパチの期待値稼働・ハイエナ立ち回りを行うプレイヤー。
- 収支記録をつけ、狙い目を素早く確認したい層。

### 1.4 収録規模（2026-08-23 時点）
- 収録機種：**309機種**（期待値・研究所の両ソース統合：134／研究所のみ：158／期待値のみ：17）
- 新台バッジ対象：15機種（掲載62日以内で自動判定）
- 期待値計算ツール搭載：100機種
- 無料サンプル（味見）公開：3機種

## 2. ビジネス要件

### 2.1 収益モデル
月額・年額のサブスクリプション（Stripe 課金）。無料登録でアカウント作成は可能だが、機種の有料コンテンツ閲覧はプレミアム会員が原則。

### 2.2 料金（税込）
| プラン | 価格 | 備考 |
|---|---|---|
| 無料登録 | ¥0 | アカウント作成・お気に入り・メモ保存・無料サンプル閲覧 |
| プレミアム（月額） | ¥780 / 月 | 全機能 |
| プレミアム（年額） | ¥5,980 / 年 | 月あたり約¥498（約36%お得） |

料金値は `src/lib/pricing.ts` に集約。

### 2.3 無料／有料の境界
| コンテンツ | 無料会員 | 無料サンプル機種 | プレミアム |
|---|---|---|---|
| 機種一覧・検索・機種ページ枠 | ○ | ○ | ○ |
| 狙い目の冒頭プレビュー（teaser・約120字） | ○ | ○ | ○ |
| 狙い目 全文 | ✕（ペイウォール） | ○ | ○ |
| 解析・設定判別 | ✕ | ○ | ○ |
| 大量集計 | ✕ | ○ | ○ |
| 期待値計算ツール | ✕ | ✕（有料維持） | ○ |
| お気に入り・メモ・稼働ログ | ○ | ○ | ○ |

### 2.4 集客方針（半クローズド）
派生データを扱う性質上、**マスへの公開は避ける**。以下を基本方針とする。
- **公開登録＋noindex**：誰でも登録できるが検索エンジンには載せない。
- **「リンクを渡した人だけ入れる」半クローズド**運用。
- **友だち紹介ループ**（相互特典）＋**ニッチ浸透**（コミュニティ等へのリンク共有）で拡大。
- 共有リンクが魅力的に開くよう **OGP を整備**（検索非公開は維持）。

## 5. 機能要件

### 5.1 認証・アカウント（Supabase Auth）
- **登録／ログイン方式**：Google OAuth、メールアドレス＋パスワード。
- **メール確認必須**（`mailer_autoconfirm = false`）。確認メール未クリック時は再送導線を表示。
- **PKCE フロー**（SPA/PWA でリロードやServiceWorker配下でも取りこぼさない）。
- **パスワード**：最低8文字。パスワード再設定（リセットメール→新パスワード設定）。
- **未ログイン時**：ランディングページ（LP）を表示。アプリ本体はログイン後のみ表示（AuthGate）。
- **退会（アカウント削除）**：二段確認（登録メール入力）→ サブスク解約 → お気に入り/ログ/メモ/プロフィール削除 → Auth ユーザー削除。

### 5.2 機種閲覧
- **一覧（ホーム）**：人気順（研究所記事件数＋新台ボーナス）で初期表示。フィルタ（新台・お気に入り・メーカー等）、最近見た機種、無料サンプル／新台バッジ表示。
- **検索**：機種名・別名・カナ揺れを正規化してインデックス検索。
- **機種ページ**：ヘッダー（サムネ・機種名・メーカー・新台/無料サンプルバッジ・お気に入り★）＋自分メモ欄＋3タブ。
  - タブ：**狙い目 / 解析・設定 / 大量集計**。
  - **狙い目クイックナビ**：見出し（リセット/天井/ゾーン/やめどき等）をチップ化し、タップで該当箇所へスクロールジャンプ。
- **内部記事**：元サイトの記事を内部ページ `/a/<id>` として復元し、外部誘導リンクの受け皿にする。

### 5.3 有料コンテンツ配信・会員判定
- 重い狙い目全文／解析／集計 HTML は機種JSONから分離し、`/data/spec/<id>.json` として遅延読込。
- 配信は **Cloudflare Pages Function（`functions/_middleware.js`）** が会員判定して制御。
  - 保護対象：`/data/spec/*`（狙い目/解析/集計JSON）、`/calc/*.html`（計算ツール）。
  - 認証：cookie `sblab`（AuthSync が設定）または `Authorization` ヘッダのトークン。
  - 判定：`profiles.plan = premium` のみ配信、それ以外は 401/403。
  - パス正規化（連続スラッシュ畳み込み＋小文字化）で `//data/spec/…` 等のバイパスを防止。

### 5.4 無料サンプル（味見）
- `data/free-samples.json`（機種名の配列）で対象を指定。ビルド時に該当機種へ `freeSample` を付与。
- **登録済みの無料会員にも**、対象機種の狙い目/解析/大量集計を**全文開放**（計算ツールは有料維持）。
- データは通常機種と同じ `/data/spec/*` に置き、middleware が「**無料サンプルID かつ ログイン済み**」なら premium 不問で配信（公開複製は作らない＝データを不用意に晒さない）。
- 対象IDはビルドが `_middleware.js` のマーカー間へ自動注入。
- UI：機種ページ/一覧/ヘッダに「無料サンプル」バッジ、本文にバナー＋アップグレードCTA。
- **重要**：新規の無料ユーザーは `profiles` 行を持たない（課金時に作成）。よって無料サンプルのログイン判定は `profiles` 有無ではなく **`/auth/v1/user`** で行う。

### 5.5 お気に入り・メモ・稼働ログ
- お気に入り（★）、機種メモ、稼働ログ（収支・機種・ゲーム数）を保存。
- ログイン中は端末間で自動同期（Supabase）。

### 5.6 期待値ツール
- **期待値計算シミュレーター**：機種スペックから開始ゲーム数別の期待値・ボーダーを算出（100機種にツールHTMLを生成、iframe表示）。
- **稼働ロガー**：実戦の収支・機種・ゲーム数を記録し振り返り。
- **下振れシミュレーター**（期待値ツール内）。

### 5.7 決済（Stripe）
- **Checkout**：本人確認 → 顧客紐付けの自己修復 → 二重購入防止（active/trialing/past_due で 409）→ 決済。
- **購入前ゲート**：20歳以上＋規約同意チェック必須、購入後ポーリングで反映確認。
- **カスタマーポータル**：解約（期間末）・支払方法変更・領収書。
- **Webhook**：署名検証。`premium = active/trialing/past_due(猶予)` / `free = canceled/unpaid/incomplete系`。`invoice.payment_failed → past_due`。
- マイページに現在プラン・次回更新日・解約予約状態を表示。

### 5.8 友だち紹介
- 紹介リンク `smasuro-lab.com/?ref=CODE`。`?ref` を localStorage 退避 → ログイン確立時に紐付け。
- 紹介コードは**無料会員でも発行可**。
- **特典**：被紹介者の初回課金時に、紹介者・被紹介者**双方へ ¥780 の Stripe クレジット**（翌月分無料）＋紹介件数加算。冪等（一度きり・実課金時のみ＝不正防止）。
- マイページに紹介UI：リンク表示／コピー／**「友だちに共有する」（Web Share API で LINE/X/Discord へ1タップ、未対応環境はコピーにフォールバック、特典入り事前メッセージ）**／紹介件数／特典説明。

### 5.9 PWA・オフライン
- Service Worker によるキャッシュ。一度見た機種は低電波・オフラインでも即表示。
- ホーム画面追加（manifest / apple-web-app 対応）。

### 5.10 共有（OGP）
- OGP / Twitter カード（summary_large_image）を整備。OG画像 `public/og.png`（1200×630）。
- **noindex は維持**（OGP は共有時のみ展開＝検索公開はしない）。

## 6. 非機能要件

### 6.1 パフォーマンス
- 狙い目（既定タブ）は機種JSONにインライン保持で即表示。重い解析/集計は遅延読込。
- 静的書き出し（SSG）＋CDN配信。PWA でオフライン即表示。
- モバイル横スクロール防止（広い表は `tbl-scroll` で内包スクロール、`overflow-x: clip`）。

### 6.2 セキュリティ
- **認証**：Supabase（RLS 前提）。anon キーは公開前提で RLS で防御。
- **RLS**：`profiles` は本人 SELECT のみ（INSERT/UPDATE ポリシー無し＝クライアントから plan 改竄・自己premium昇格不可）。`favorites/logs/notes` は本人行のみ ALL（`auth.uid() = user_id`）。plan 更新は Webhook（service_role）のみ。
- **有料コンテンツ保護**：middleware による会員判定配信（§5.3）。
- **秘密情報**：Stripe秘密鍵・whsec・SMTP等は Supabase secrets のみに保持（ファイル/git 非記載）。
- **Edge Functions**：全て `verify_jwt = false`（CORSプリフライト対策）＋関数内 `getUser` で本人確認。CORS は smasuro-lab.com 限定。

### 6.3 プライバシー・公開範囲
- 全ページ `robots: noindex, nofollow`。
- 半クローズド運用（§2.4）。データの不用意な公開を避ける（無料サンプルもログイン必須）。

### 6.4 可用性・保守性
- Cloudflare Pages（グローバルCDN）。デプロイは即時・イミュータブル。
- データ更新はローカルでビルド→生成物コミット→デプロイの単純パイプライン（§11）。

### 6.5 対応環境
- モバイル（スマホ）優先設計。PC（サイドバー表示）も対応。
- 日本語UI。見出しの折り返し整形（text-wrap/palt 等）に配慮。

## 8. データ設計

### 8.1 Supabase テーブル
- **profiles**：`user_id, plan('free'|'premium'), stripe_customer_id, stripe_subscription_id, subscription_status, current_period_end, cancel_at_period_end, referral_code(unique), referred_by(uuid), referral_count, referral_rewarded`
  - ※ profiles 行は課金/紐付け時に作成される（新規無料ユーザーは行なしが正常）。
- **favorites / logs / notes**：本人行のみ（RLS）。お気に入り・稼働ログ・機種メモ。

### 8.2 静的データ（ビルド生成物）
| 出力 | 内容 |
|---|---|
| `src/data/index.json` | 機種一覧＋検索索引（`freeSample` フラグ含む） |
| `src/data/machines/<id>.json` | 機種メタ＋teaser（重い本文は分離） |
| `public/data/spec/<id>.json` | 狙い目全文/解析/集計（保護配信） |
| `src/data/articles/<id>.json` | 内部記事（外部リンクの受け皿） |
| `public/calc/<id>.html` | 期待値計算ツール（保護配信） |
| `public/og.png` | OGP画像 |

### 8.3 データパイプライン（`build-data.mjs`）
- 期待値サイト（suroschool）と研究所（slolabo）の機種を**名称正規化で統合**（強制統合・重複検知つき）。
- HTMLクリーニング、**外部リンク内部化**、ツールUI残骸除去、表の横スクロール内包。
- **情報不変リライト**の適用（§10.1）と表示ゲート。
- 狙い目クイックナビ生成、teaser 生成、無料サンプルID注入。

## 10. コンテンツ制約・コンプライアンス

### 10.1 情報不変リライト（必須ゲート）
- 元データの文章をそのまま転載しない方針。**数字の欠落0・捏造0**を機械検証で担保したリライトのみ表示。
- 未リライト／検証NGのコンテンツは「準備中」に留める（原文コピーは出さない）。

### 10.2 サイト内完結
- 参考元/出典等の外部誘導セクションは除去。元サイトの機種/記事リンクは内部URL（`/m/`・`/a/`）へ書換。その他外部リンクはテキスト化。

### 10.3 検索非公開
- `noindex, nofollow` ＋ robots で検索エンジンからの流入を遮断。

### 10.4 法務・年齢
- **利用規約 / 特定商取引法に基づく表記 / プライバシーポリシー** を掲載。
- **20歳未満は利用不可**（購入前チェック・フッター明記）。
- 反社会的勢力排除条項、最低利用期間なし。
- 「情報提供を目的とし、遊技結果・収支を保証しない」旨を明記。

## 11. 運用要件

### 11.1 デプロイ手順
1. （データ変更時）`node scripts/build-data.mjs` → `node scripts/build-calc.mjs`
2. `npx next build`
3. `npx wrangler pages deploy out --project-name=smasuro-lab --branch=main`

### 11.2 月次データ更新
- REST 方式で一次データを取得 → 統合ビルド → デプロイ（認証不要・約1分）。丁寧・低負荷アクセスを厳守。

### 11.3 テスト手法
- 使い捨てメール（mail.tm ドメイン emalupe.com）で登録→確認→検証。
- **掃除は必ず `@emalupe.com` 限定**。実在アカウント（owner／ひな 等 `@gmail.com`）は削除・改変禁止。

### 11.4 モニタリング
- Cloudflare のリクエスト統計。Web Analytics は要有効化（未設定・§14）。

## 12. 制約・前提
- 一次データは外部サイト由来。取得は丁寧・低負荷で行い、表示は情報不変リライト後のみ。
- データの公開範囲を最小化（半クローズド／noindex／サンプルもログイン必須）。
- 個人運営。運用はローカルビルド＋CDNデプロイの軽量構成。
- 実在会員データの保護を最優先（テスト掃除の誤操作を避ける運用ルール）。
